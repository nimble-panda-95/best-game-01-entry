Starlight Courier is a gravity-slingshot arcade game: pilot a comet courier through six hand-built star systems, collect every star shard, dodge mines and gravity wells, and reach the gate. Built with vanilla JavaScript, Canvas 2D, and synthesized WebAudio sound — no build step, no network requests, no downloaded assets.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
